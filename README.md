## Getting Started

Create a new Gatovel application with Composer:

```bash
composer create-project gatovel/framework my-site
```

After creating the project, the interactive installer lets you choose which optional Gatovel components should be installed.

Available components include:

- `gatovel/cli`
- `gatovel/database`
- `gatovel/auth`

The Gatovel Core remains independent from these optional packages.
